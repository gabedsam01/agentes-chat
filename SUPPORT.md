# Support

**[GitHub Discussions](https://github.com/gabedsam01/squad-chat/discussions) is the support channel.**
Ask anything there: self-hosting, model keys, connectors, agent computers, development.

[Issues](https://github.com/gabedsam01/squad-chat/issues) are for confirmed bugs and concrete feature
requests (the issue forms will guide you). Security reports go through [SECURITY.md](SECURITY.md),
never a public issue.
